  <h2>📌 About CluckTrack</h2>
  <p style="line-height: 1.6;"><strong>CluckTrack</strong> is an enterprise-grade Agricultural ERP web application engineered to modernize poultry farm management. Developed as an academic capstone project, it eliminates error-prone paper ledgers and disconnected Google Sheets, replacing them with a unified real-time dashboard that tracks dynamic inventory, monitors daily production yields, and processes predictive analytics for optimized farm profitability.</p>

  <br>

  <h2>⚙️ Automated Installation & Setup Guide</h2>
  
  <h3>📋 Prerequisites</h3>
  <ul>
    <li><b>XAMPP</b> (or any local LAMP/WAMP server stack supporting <b>PHP 8.x</b> and <b>MySQL</b>)</li>
    <li><b>Python 3.x</b> (Required for running the predictive forecasting analytics engine)</li>
    <li><b>Git</b> (For version control and repository cloning)</li>
  </ul>

  <h3>Step 1: Clone the Repository</h3>
  <p>Open your terminal and run the following command:</p>
  <pre style="background: #1f2937; color: #f87171; padding: 10px; border-radius: 6px; font-family: monospace;"><code>git clone https://github.com/alyssamaetdeguzman/clucktrack.git</code></pre>

  <h3>Step 2: Move to Local Server Root Directory</h3>
  <p>Move the cloned folder into your local server web root directory (e.g., <code>C:\xampp\htdocs\clucktrack</code> for XAMPP).</p>

  <h3>Step 3: Initialize and Configure the Database</h3>
  <ol>
    <li>Start <b>Apache</b> and <b>MySQL</b> modules from your XAMPP Control Panel.</li>
    <li>Open your browser and navigate to phpMyAdmin: <code>http://localhost/phpmyadmin</code></li>
    <li>Create a new database named <b><code>clucktrack_db</code></b>.</li>
    <li>Select the database, click the <b>Import</b> tab, upload <code>database/schema.sql</code>, and click <b>Go</b>.</li>
  </ol>

  <h3>Step 4: Configure Database Connection</h3>
  <p>Open <code>config/db.php</code> in your code editor and verify your database settings:</p>
  <pre style="background: #1f2937; color: #f87171; padding: 10px; border-radius: 6px; font-family: monospace;"><code>&lt;?php
$host = 'localhost';
$db   = 'clucktrack_db';
$user = 'root';
$pass = ''; // Default XAMPP password is blank

try {
    $pdo = new PDO("mysql:host=$host;dbname=$db;charset=utf8mb4", $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC
    ]);
} catch (\PDOException $e) {
    throw new \PDOException($e->getMessage(), (int)$e->getCode());
}
?&gt;</code></pre>

  <h3>Step 5: Install Python Dependencies</h3>
  <p>Navigate to the python engine folder in your terminal and install the required packages:</p>
  <pre style="background: #1f2937; color: #f87171; padding: 10px; border-radius: 6px; font-family: monospace;"><code>cd path/to/clucktrack/python_engine
pip install -r requirements.txt</code></pre>

  <h3>Step 6: Launch the Application</h3>
  <p>Open your browser and navigate to: <b><code>http://localhost/clucktrack/index.php</code></b></p>
